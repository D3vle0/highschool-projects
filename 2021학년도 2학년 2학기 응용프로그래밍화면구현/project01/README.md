# project01

React의 기본 개념(컴포넌트 분리, Props, State, 생명주기, 이벤트 처리)을 날짜별로 단계적으로 학습한 실습 프로젝트입니다.

- **0927**: 컴포넌트 기초 분리(`Header`, `Nav`, `Article`) 및 ES6 문법(전개 연산자, 구조 분해 할당, 쿼리스트링 파싱)
- **0928**: 컴포넌트 `Props` 전달 및 `PropTypes`를 활용한 데이터 유효성 검증
- **1005**: `State` 관리, 생명주기 메서드(`constructor`, `componentDidMount`), `forceUpdate` 비동기 상태 갱신
- **1012**: 이벤트 처리를 통한 카운터(`Counter`) 및 부모-자식 컴포넌트(`MyComponent`) 간 데이터 전달
